# Swiss Demographics Explorer

A React + Vite dashboard for Swiss demographic analysis, built with interactive charts and canton-level filtering.

## Features

- Population comparison across cantons
- Regional filtering by North, Central, West, East, and South
- Canton detail cards with age, migration, and growth metrics
- Population trend line chart and age distribution pie chart
- Responsive dashboard layout for desktop and mobile

## Tech stack

- React 18
- Vite 5
- Recharts 2

## Getting started

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview -- --host
```
